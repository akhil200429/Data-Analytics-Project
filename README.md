# Data-Analytics-Project
An 18-page report by Mayadhar Tiwari analyzing a synthetic Myntra-style dataset (240 records, 5 June 2026 dates, 8 states, 6 categories), not real data. It shows 44.84 lakh orders and ₹656.07 crore GMV, Women's Fashion and Maharashtra leading, 96.90% success rate, 4.55/5 CSAT, and notes limitations and predictive next steps.
